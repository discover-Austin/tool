SECTION 5: ADDITIONAL CONTEXT
================================================================================

This app is designed to be 100% offline and privacy-first. All project data, 
measurements, and calculations are stored locally on the user's device using 
Android's DataStore. No data is transmitted to servers, and no third-party 
services are integrated.

The only permission requested is Storage Access Framework (SAF) for user-
initiated file exports (PDF/CSV/JSON/PNG), which gives users explicit control
over where files are saved.

No analytics, crash reporting, advertising, or tracking of any kind is 
implemented.
